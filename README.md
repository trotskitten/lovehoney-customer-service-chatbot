# RAG Customer-Service Chatbot

## Overview

This project is a portfolio MVP for a retrieval-augmented generation customer-service chatbot.

## MVP Features

- RAG over customer-support documents
- Chroma vector retrieval
- OpenAI-generated answers
- Source display
- Basic safety rules
- CSV logging
- Basic evaluation

## Tech Stack

- Python
- Conda
- LangChain
- OpenAI API
- Chroma
- Streamlit
- pandas
